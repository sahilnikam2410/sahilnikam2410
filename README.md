- 🛡️ **Founder & security lead of [VRIKAAN](https://vrikaan.com)**, an AI-powered cyber defence platform for people who are not security professionals.
- 🏅 Recognised in **The Cyber 50: India's Elite Founders List** (Indian Startup Times).
